# WorldMirror demo clips

Drop the four MP4 files below into this folder. The homepage already has a poster and player for each slot.

- `01-overview.mp4` — 25–35s split screen: RGB demonstration → reconstructed scene → replay.
- `02-scene-reconstruction.mp4` — 30–45s scene/asset reconstruction, ideally tabletop or sink.
- `03-trajectory-replay.mp4` — 20–40s wrist-view replay, with real and simulated views aligned.
- `04-verification-loop.mp4` — 25–40s mismatch → agent correction → validation success.

Recommended export: H.264 MP4, 1080p, 16:9, muted by default, with short captions burned in.
